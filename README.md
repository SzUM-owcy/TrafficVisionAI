# TrafficVisionAI
🚦AI-powered traffic detection using YOLO for real-time object recognition in traffic images.

# Info
Project uses YOLOv5 model for traffic detection.
Dataset is from kaggle: https://www.kaggle.com/datasets/yusufberksardoan/traffic-detection-project

After all data augmentations and improvements our model reaches performance statisics of:
Precision: 0.933
Recall: 0.904
mAP50: 0.945
mAP50-95: 0.707
Values were computed on test split of dataset.

More detailed information can be found in our report included in this repository.
